# RESCUEFLOW AI — Project Plan

## Goal
Build a learning/demo web app that helps coordinate **simulated** emergency reports.

## Planned roles
- Admin
- Emergency coordinator
- Rescue team member (demo account only)

## Planned modules
- Authentication and role-based access
- Dashboard
- Simulated incident reporting and history
- Incident analysis and priority classification
- Sample team directory and availability
- Suggested team matching
- Coordinator approval
- Simulated assignment records
- Reports and analytics

## Development rule
Build and test one module at a time. Do not claim a feature works until it has
been implemented and tested.
